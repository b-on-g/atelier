# Ателье глифов

Рисуй магические глифы, как в манге «Ателье колдовских колпаков» (Witch Hat Atelier):
кольцо, сигил в центре, знаки по краю. Пока в кольце разрыв, глиф спит. Замкни его, и
заклинание оживёт.

**Сайт:** https://b-on-g.github.io/atelier/

- **Курс** — 16 глифов из манги: водяной выстрел Коко, урок Агот, огненный шар, хватающий
  ветер, разрушитель стен и другие. Глиф уже начерчен, дорисуй разрыв в кольце.
- **Лист** — рисуй свой глиф пером, пальцем или мышью, или ставь штампы из палитры.
- **Гримуар** — сигилы и знаки с пометкой, что из манги, а что додумано.

## Как устроено

Пак MAM на [$mol](https://github.com/hyoo-ru/mam_mol). Каст рисует игровой движок
[bog/gamengine](https://github.com/b-on-g/gamengine): лист бумаги в объёме, частицы
стихии, свет и bloom.

| Модуль | Что делает |
|---|---|
| `ink` | геометрия штриха: подгонка окружности, разрыв кольца по покрытию углов |
| `read` | распознаватель `$P` point-cloud |
| `lexicon` | сигилы и знаки как векторные построения, из них же шаблоны и иконки |
| `glyph` | разбор листа: кольцо, сигил, знаки в позе кольца, перевёрнутые знаки |
| `spell` | смысл по канону: стихия, сила от размера, длительность от аккуратности, наклон к длинному знаку |
| `cast` | сцена движка |
| `desk`, `stage` | лист для рисования и переключение в каст |
| `course`, `workshop`, `grimoire`, `app` | экраны |

Разбор канона — [LORE.md](./LORE.md), разбор чужих симуляторов — [RIVALS.md](./RIVALS.md),
принятые решения — [DECISIONS.md](./DECISIONS.md).

## Запуск

```bash
git clone https://github.com/hyoo-ru/mam.git && cd mam
npm install && npm start
# http://localhost:9080/bog/atelier/app/-/test.html
```
